# HCLI

Welcome to the HCLI github page!

## What is HCLI?

Well, HCLI is a small compact CLI or powershell like interface that I've been developing for some time now. The base idea is about a CLI framework that you can expend with your own custom commands with their own logic. 

## Modules?

With HCLI alone, you have access to many quality of life commands, but you can expand it with whole other CLI programs with the help of modules. These can be made by anyone and they can add custom commands or whole CLI programs within this framework. 

## I don't get what this is...

You could imagine this as a "no GUI OS" but as a student project, with a much smaller scale (basically a program). Within this OS, you can find quality of life commands and you can expend this with modules, custom commands.

## Why this as a "dream" project? 
Well, I noticed that I really like to build "system" like programs.
For example, when I think about what has Terry A. Davis has achieved with Temple OS I'm always flattered and motivated to create my own little system that I can work in and even document.
